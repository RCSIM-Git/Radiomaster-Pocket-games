POKEMON CLASSIC - EDGETX 128x64 MONOCHROME LCD EDITION
================================================================================

Authentic Game Boy Gen 1 Pokemon Red / Blue RPG for EdgeTX radios!
Optimized specifically for RadioMaster Pocket and MT12 128x64 monochrome LCD.

FEATURES:
- Full Tile-based Overworld (Pallet Town, Route 1, Tall grass, houses, fences)
- 4-way D-Pad walking via Transmitter Gimbals/Sticks
- Wild Pokemon encounters in tall grass (~18% chance)
- Turn-based Battle Engine (Player vs Wild Pokemon)
- 4 Starters to choose from: PIKACHU, CHARMANDER, SQUIRTLE, BULBASAUR
- Wild roster: PIDGEY, RATTATA, CATERPIE, rare wild PIKACHU
- Battle actions: FIGHT (moves with power, PP, and typing), BAG (Poke Balls, Potions), RUN
- Real Poke Ball catching mechanic with animated wiggles and catch probability!
- Level-up system with stat growth (HP, ATK, DEF, SPD) and EXP
- In-game Start Menu with SAVE function (persists to SD card!)
- 8 genuine 8-bit chiptune WAV sound effects

CONTROLS:
- Movement (Overworld): Gimbals / Sticks (AIL/ELE/RUD)
- Menu Navigation: Scroll Roller Wheel
- Select / Confirm / Attack: Press Roller [ENT]
- Cancel / Back / Open Start Menu: Press [RTN]
- Quick Rest / Heal party at home: Flip Switch [SE]

SOUND ASSETS:
Place WAV files in: /SOUNDS/POKEMON/
- intro.wav
- battle.wav
- hit.wav
- catch.wav
- faint.wav
- levelup.wav
- select.wav
- run.wav
