================================================================================
BAD APPLE!! (Pocket Edition) for EdgeTX (128x64 Monochrome LCD)
================================================================================
Kompatybilność: RadioMaster Pocket, MT12, Boxer, TX12, Zorro

Pliki na karcie SD:
1. /SCRIPTS/TOOLS/BadApple.lua          -> Główny skrypt narzędzia EdgeTX
2. /SCRIPTS/TOOLS/BADAPPLE/badapple.dat -> Skompresowane klatki wideo (4384 klatki @ 20 FPS, 988 KB)
3. /SCRIPTS/TOOLS/BADAPPLE/badapple.idx -> Indeks klatek z analizatorem audio (34 KB)
4. /SOUNDS/MUSIC/badapple.wav          -> Ścieżka dźwiękowa (PCM 16-bit Mono 32kHz, 13.7 MB)

Funkcje i działanie:
- AUTO-PLAY: Włącza się OD RAZU po wybraniu z menu Tools (bez uciążliwych menu)
- Płynny streaming wideo 20 FPS bezpośrednio z karty SD
- Tryb "4:3 RETRO THEATER" z animowanym sprzętowym analizatorem widma (4 pasma EQ)
- Tryb "128x64 FULLSCREEN" (rozciągnięty na cały ekran)

Wygodne sterowanie dopasowane do RadioMaster Pocket:
- Przycisk na prawym górnym barku [SE] lub klik rolki [ENT]:
    * Pauza / Wznowienie odtwarzania
- Drążek w prawo / w lewo (lub obrót rolki):
    * Płynne przewijanie wideo w przód / w tył o 5 sekund (+/- 100 klatek)
- Drążek w górę (lub przycisk [PAGE]):
    * Błyskawiczne przełączanie trybu 4:3 Kinowy <-> Pełny ekran
- Drążek w dół:
    * Odwrócenie kolorów (Negatyw / Pozytyw)
- Rolka S1 / P1:
    * Płynna sprzętowa regulacja głośności (1..5)
- Przycisk [RTN / EXIT]:
    * Zatrzymanie odtwarzania i czysty powrót do menu radia
