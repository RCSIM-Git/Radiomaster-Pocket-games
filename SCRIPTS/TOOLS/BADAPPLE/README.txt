================================================================================
BAD APPLE!! (Pocket Edition) for EdgeTX (128x64 Monochrome LCD)
================================================================================
Compatibility: RadioMaster Pocket, MT12, Boxer, TX12, Zorro, and 128x64 radios.

SD Card Files:
1. /SCRIPTS/TOOLS/BadApple.lua          -> Main EdgeTX tool script
2. /SCRIPTS/TOOLS/BADAPPLE/badapple.dat -> Compressed video frames (4384 frames @ 20 FPS, 988 KB)
3. /SCRIPTS/TOOLS/BADAPPLE/badapple.idx -> Frame index with audio spectrum data (34 KB)
4. /SOUNDS/MUSIC/badapple.wav          -> Audio track (PCM 16-bit Mono 32kHz, 13.7 MB)

Features:
- AUTO-PLAY: Starts playing IMMEDIATELY upon selection from the Tools menu
- Smooth 20 FPS video streaming directly from the MicroSD card
- "4:3 Retro Theater" mode with animated 4-band hardware audio spectrum visualizer
- "128x64 Fullscreen" mode (stretched to full LCD width)
- Color inversion toggle (Negative / Positive)

Controls (RadioMaster Pocket):
- Top-Right Shoulder Button [SE] or Click Roller [ENT]:
    * Play / Pause playback
- Stick Right / Left (or Scroll Roller):
    * Fast-forward / Rewind 5 seconds (+/- 100 frames)
- Stick Up (or [PAGE] Button):
    * Instant toggle between 4:3 Theater Mode <-> Fullscreen Mode
- Stick Down:
    * Invert LCD pixels (Negative / Positive)
- Potentiometer S1 / P1:
    * Smooth hardware volume adjustment (Levels 1..5)
- Return Button [RTN / EXIT]:
    * Stop playback and cleanly exit back to EdgeTX menu
